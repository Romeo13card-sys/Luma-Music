Обновление относительно **1.1**. Устанавливайте APK поверх текущей версии — прежние пакет, сертификат и данные сохранены.

Для большинства телефонов нужен **Luma-Music-1.2-arm64-v8a.apk**; для старых 32-битных ARM — armeabi-v7a. Universal содержит все четыре архитектуры.


### Добавлено

- Новый Android-плеер: компактные кнопки с векторными иконками, избранное рядом
  с названием, отдельные переходы к тексту, очереди, загрузке и таймеру сна.
  Обложки и цвет альбома из 1.1 сохранены, без стекла и размытия.
- Свайп по обложке и мини-плееру переключает треки, в том числе при медленном
  движении пальца. Кнопка «Назад» сворачивает плеер.
  Мини-плеер показывает тонкую полосу прогресса.
- Отдельная очередь: «следующим», добавление в конец, перемещение выше/ниже,
  удаление и очистка. Общее меню трека доступно из поиска, коллекции и очереди;
  для треков Яндекса есть отправка и копирование ссылки.
- Добавление/удаление избранного и отметок «Не нравится». Rust сохраняет новое
  состояние только после подтверждения API; если статус неизвестен, меню предлагает
  явные действия. В Моей волне подтверждённая реакция отправляется как feedback,
  а дизлайк текущего играющего трека переключает его.
- «Коллекция»: избранное и «Не нравится» с постраничной загрузкой вместо первых
  100 избранных. Метаданные загружаются страницами по 20/40 элементов;
  индекс ограничен 5000 ID на раздел, очередь — 200 треками.
- Настройка Моей волны по образцу мобильной YAYMA: 13 отдельных подборок
  для занятий, настроения и языка. Выбор сохраняется в Rust SQLite.
  Подключён протокол сессий rotor/session с продолжением и feedback;
  для персональной волны оставлен резервный прежний endpoint.
- Главная с быстрыми переходами и последним треком, обновлённые строки коллекции,
  отдельная отправка поискового запроса с клавиатуры.

### Исправлено

- Изменение порядка сохраняет текущий слот, включая одинаковые треки, и позицию
  воспроизведения. Редактирование на паузе не запускает музыку.
- Ручное переключение игнорирует повтор одного трека; «предыдущий» после пяти
  секунд возвращает к началу. Переключение на паузе сохраняет паузу;
  пауза во время подготовки аудио отменяет автоматический старт.
- Устаревшее меню очереди не удаляет другой трек после изменения списка.
  Нажатия на ещё не перерисованные строки также проверяют ревизию списка.
- Feedback вынесен из потока подготовки аудио в отдельную ограниченную очередь.
  При быстрых переключениях устаревшие ожидающие запросы пропускаются до обращения к сети.
- Индекс коллекции изолирован по аккаунту: выход/смена аккаунта очищает его;
  запоздалые ответы не заменяют состояние после подтверждённой отметки.
- Альбом сохраняется в очереди для корректных составных ID Яндекса.
  Истёкшие сессии волны, токены и URL потоков в очередь на диске не записываются.

### Ресурсы и обновление

- Нативные Views / Material 3, без Flutter и постоянно работающих анимаций.
  Кэш коллекции живёт 60 секунд, содержит ID, а не весь каталог; нет фонового
  опроса коллекции. Экран очереди переиспользует строки и обновляется только видимым.
- Ограничения кэша обложек из 1.1 сохранены: 2 МиБ Bitmap, 24 МиБ на диске,
  100×100 / до 400×400. Это лимиты отдельных кэшей, не обещание общего расхода ОЗУ.
- Android 11+, SDK 36; ARMv7, ARM64, x86, x86_64 и universal.
  VersionCode 22, прежний org.luma.music и сертификат: обновление поверх 1.1,
  1.0 и 0.5.0 без удаления приложения. Название/APK — 1.2, OTA-тег — v1.2.0.

### Ограничения

- Неофициальные API избранного, реакций и подборок зависят от аккаунта, подписки
  и доступности сервиса. Автотесты не подтверждают работу на настоящем аккаунте;
  серверная ошибка показывается в приложении, успех без подтверждения не рисуется.
- Выбирается одна подборка, а не комбинация фильтров оригинального приложения.
  В коллекциях больше 5000 треков видна доступная часть с указанным лимитом.
- Это адаптация возможностей и навигации YAYMA под нативный Android, а не полный
  перенос Flutter-интерфейса, DSP или всех API. Upstream GPL-снимок не изменён.
- Desktop не получил новый Android-интерфейс. Ограничения Spotify-аудио,
  очереди загрузок и докачки остаются прежними.

### Проверки выпуска

- 69 тестов Rust-ядра, 3 desktop, 8 JVM и 8 Python; Android Lint без ошибок.
- Подписанные release APK: обновление 1.1 → 1.2 на Android API30/33, эмуляторы с 2ГБ, сохранение UID/установки, запуск и повторный запуск процесса.
- Интеграция: локальное аудио, обложки в обеих темах, очередь/пауза/свайп, устаревшее меню, выбор волны, тексты и 35 локалей.
- Сетевые реакции и подборки на настоящем аккаунте этими тестами не проверены.
