# Luma Music 2.0.0

Первый стабильный выпуск поколения 2.0.

## Основное
- Полностью обновлённый интерфейс Android.
- Обновлённая Desktop-оболочка.
- Улучшенная система OTA-обновлений GitHub.
- Возобновление прерванных загрузок.
- Проверка SHA-256 и целостности APK.
- Пять APK для ARMv7, ARM64, x86, x86_64 и Universal.

## Важно при переходе с 1.3
В версии 2.0 используется новый постоянный сертификат подписи.
Android потребует удалить версию 1.3 перед установкой 2.0.
Удаление приложения может привести к потере локальных данных.
Сделайте резервную копию важных данных заранее.

Последующие обновления 2.x будут устанавливаться обычным способом.
