# Luma Music 2.1.0

Стабильный выпуск Luma Music 2.1.0.

## Основное

- Ускорена подготовка аудиопотока на Android: предварительное разрешение адресов выполняется в фоне.
- Rust-ядро объединяет одновременные запросы одного трека и качества.
- Добавлен краткоживущий кэш адресов потоков с разделением по аккаунтам.
- Desktop использует общий кэш потоков и предварительно подготавливает следующий трек.
- Добавлена проверка стабильных GitHub-релизов и загрузка подходящего ZIP-архива для текущей ОС и архитектуры.
- Реализована проверка SHA-256 загруженного Desktop-архива.
- Добавлена установка проверенного Desktop-архива с перезапуском приложения на Windows, Linux и macOS.
- Улучшены мини-плеер и отображение состояния подготовки трека на Android.
- Добавлены регрессионные тесты конкурентного разрешения потоков и предварительной загрузки.

## Android APK

- Package: org.luma.music
- Version: 2.1.0
- Version code: 28
- Подготовлены ARMv7, ARM64, x86, x86_64 и Universal.

## Важно

Проверка SHA-256 выполняется перед использованием опубликованных Desktop-архивов. Практическое тестирование установщика на каждой поддерживаемой ОС ещё требуется.

Для установки Android APK выберите вариант, соответствующий архитектуре устройства. Для большинства современных Android-смартфонов подходит ARM64.

Последующие обновления 2.x используют постоянный сертификат подписи Luma Music.
