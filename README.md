# Luma Music

**made by Romeo13card**

Неофициальный музыкальный клиент Яндекс Музыки. Android-клиент использует нативный Kotlin UI и Rust-ядро; Desktop-клиент написан на Rust/egui. Вход в Яндекс выполняется через OAuth — Luma не запрашивает и не сохраняет пароль Яндекса.

> **Состояние проекта:** стабильная версия исходников — 2.1.0. Публичный установочный релиз будет опубликован после проверки и подписания APK постоянным сертификатом проекта.

## Что умеет приложение

### Android
- OAuth-вход в Яндекс Музыку, проверка профиля и защищённое хранение токена.
- Поиск треков, альбомов, исполнителей и плейлистов; страницы каталога и управление собственными плейлистами.
- Воспроизведение, очередь, перемешивание, повтор, фоновый сервис, Android MediaSession и системное уведомление.
- Избранное, локальная история, закладки, резервное копирование и восстановление пользовательских данных.
- Офлайн-загрузка треков с постоянной очередью заданий и локальной библиотекой.
- Тексты песен, локальные аудиофайлы и экспериментальная «Моя волна».
- Настраиваемое качество потока, темы, язык, размер текста, таймер сна и параметры производительности.
- Проверка обновлений GitHub Releases, сохранение незавершённого APK, продолжение загрузки и проверка SHA-256/подписи перед установкой.

Функции, зависящие от неофициального API Яндекса, могут измениться без предупреждения. Работа «Моей волны» и отдельных действий с плейлистами требует проверки на реальных аккаунтах.

### Desktop
Desktop-клиент использует то же Rust-ядро. В текущей версии доступны основная навигация, поиск, избранное, «Моя волна», очередь и управление воспроизведением. Сборка и тесты проверяются в CI на Linux, Windows и macOS. Для каждого выпуска готовятся отдельные архивы под поддерживаемые ОС; в настройках доступна проверка последнего стабильного релиза GitHub, кнопка загрузки скачивает архив для текущей ОС/архитектуры и проверяет опубликованный SHA-256 перед сохранением в `Downloads`; отдельная команда запускает установщик, который после закрытия приложения распаковывает архив, заменяет portable-файлы или `.app` и перезапускает Desktop. Установка требует права записи в каталог приложения; на Linux нужен `unzip` или `python3`. Полное функциональное соответствие Android ещё не заявляется.

### iOS (preview)
В репозитории есть экспериментальный SwiftUI-клиент для iOS Simulator. Он не является IPA для установки на iPhone. Распространение обновлений на физических устройствах возможно только через подписанную сборку и TestFlight/App Store после настройки Apple Developer credentials.

### Spotify
Интеграция использует Spotify OAuth и Web API. Требуется собственный публичный Client ID через `LUMA_SPOTIFY_CLIENT_ID`. Секрет приложения не встраивается в исходники. Luma не загружает и не воспроизводит аудиокаталог Spotify; поддерживаемые действия могут открывать официальное приложение Spotify.

## Android: совместимость

- Минимум: Android 11 / API 30.
- Compile SDK / Target SDK: 36.
- Package ID: `org.luma.music`.
- ABI: `armeabi-v7a`, `arm64-v8a`, `x86`, `x86_64`.
- Поддерживаются отдельные APK для ABI и универсальный APK.

**Не меняйте** package ID или постоянный сертификат подписи: это нарушит обновление поверх существующей установки и доступ к защищённым данным.

## Сборка Android

Проверенная конфигурация проекта: JDK 17/21, Rust 1.90.0, Android SDK Platform 36, Build Tools 36.0.0, NDK 27.2.12479018 и Gradle Wrapper 8.13.

Установите Rust targets:

```sh
rustup target add \
  armv7-linux-androideabi \
  aarch64-linux-android \
  i686-linux-android \
  x86_64-linux-android
```

Проверьте Rust и упаковочные скрипты, затем соберите Android:

```sh
cargo test -p yamusic-core --locked
python3 -m unittest discover -s scripts -p 'test_*.py'

export ANDROID_HOME=/path/to/android-sdk
./scripts/build-android.sh

cd android
./gradlew testReleaseUnitTest lintRelease
cd ..

python3 scripts/package-apks.py
```

Готовые APK и `SHA256SUMS.txt` размещаются в `android/app/build/outputs/distribution/<version>/`.

Если изменялся Rust-код, сначала запустите `scripts/build-android.sh`: одного Gradle-запуска недостаточно для обновления JNI-библиотек.

## Сборка Desktop

На Linux потребуются системные библиотеки ALSA, XKB, Wayland и Mesa:

```sh
sudo apt-get install \
  libasound2-dev \
  libxkbcommon-dev \
  libxkbcommon-x11-dev \
  libwayland-dev \
  libgl1-mesa-dev
```

Затем:

```sh
cargo test --locked -p yamusic-core -p luma-desktop
cargo build --release --locked -p luma-desktop
```

## OAuth, данные и обновления

- Токен Яндекса на Android шифруется AES-GCM с ключом Android Keystore.
- Пароли и OAuth-токены не должны попадать в логи, резервные копии или SQLite-настройки.
- GitHub API не требует встроенного пользовательского токена.
- APK из OTA проверяется по размеру, SHA-256, package ID, версии и сертификату подписи.
- Незавершённая загрузка хранится в приватном каталоге приложения. Возобновление разрешено только для того же GitHub release asset.
- Установка APK остаётся системным действием Android и требует разрешения пользователя.
