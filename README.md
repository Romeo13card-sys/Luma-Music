# Luma Music · Жидкое стекло

made by Romeo13card

Неофициальный Android-клиент Яндекс Музыки: Rust-ядро, нативный Kotlin-интерфейс,
без WebView и Compose. Тестовая версия 0.3.1, applicationId `org.luma.music`.

## Совместимость и APK

Минимум Android 11 (API 30). `compileSdk = targetSdk = 36` (Android 16).
Android 17 / SDK 37 больше не используются для сборки. Это не запрет установки
на более новых ОС: `maxSdkVersion` намеренно не задаётся.

Поддерживаются четыре архитектуры:

| APK | Архитектура |
| --- | --- |
| `Luma-Music-0.3.1-test-armeabi-v7a.apk` | ARMv7, 32 бит |
| `Luma-Music-0.3.1-test-arm64-v8a.apk` | ARM64 / aarch64 |
| `Luma-Music-0.3.1-test-x86.apk` | x86 / i386 |
| `Luma-Music-0.3.1-test-x86_64.apk` | x86_64 |
| `Luma-Music-0.3.1-test-universal.apk` | Все четыре ABI |

Все файлы имеют отладочную подпись. Для телефона выбирайте APK его архитектуры:
универсальный больше по размеру. Нативные ELF и ZIP имеют выравнивание 16 КБ.
Запуск старой сборки на Android 13 подтверждён пользователем; это не заменяет
проверку нового APK и каждой ABI на устройствах.

## Что работает в коде

- Личный OAuth-токен, проверка аккаунта, шифрование Android Keystore / AES-GCM.
- Браузерный OAuth-вход с собственным Client ID и Redirect URI `yamusicrust://oauth`.
  Проверяется одноразовый state. Пароль Яндекса приложение не запрашивает.
- Поиск, плейлисты, первые 100 избранных треков.
- Экспериментальная «Моя волна»: партии, feedback начала/окончания/пропуска,
  продолжение потока. Нужны аккаунт, подписка и доступ к неофициальному API;
  работа волны на реальном аккаунте пока не подтверждена.
- Фоновый плеер, MediaSession, уведомление, перемотка, повтор и перемешивание.
- Сохранение до 200 метаданных очереди и позиции; без токена и URL аудиопотоков.
- Свои файлы через системный выбор документов. Демо со своим тестовым звуком.

## Интерфейс 0.3.1

Новый экран входа: компактная стеклянная карточка, показ/скрытие токена,
отправка с клавиатуры, блокировка повторных запросов и понятный статус ошибки.
Токен не попадает в исходники, CI и логи; не отправляйте его в чат.

Экран «Настройки» содержит только `made by Romeo13card`. Назад — системным
жестом/кнопкой. Выход из аккаунта расположен на главной и требует подтверждения.
Повтор и перемешивание остаются в плеере.

Стекло включает прозрачные панели, градиентные кромки, блики и фоновую линзу.
На Android 12+ обычного профиля дополнительно размывается декоративный фон.
Это собственное оформление, не точная копия iOS и не размытие живого содержимого
под каждой панелью. Нет непрерывного цикла анимации, скриншотов экрана и больших
буферов размытия всего интерфейса.

## Память и производительность

Профиль выбирается один раз на экран Activity. Экономичный режим включается
для low-RAM устройств, ОЗУ до 3 ГиБ или небольшого Java heap:

| Ограничение | Экономичный профиль | Обычный профиль |
| --- | --- | --- |
| Строк на странице | 20 | 40 |
| Обновление плеера на видимом экране | 1 раз/с | 2 раза/с |
| Размытие фона / декоративная линза | Выключены | Включены, API 31+ для размытия |
| Сохранённая очередь | До 200 метаданных | До 200 метаданных |

Страницы заменяют предыдущие View. При смене экрана освобождаются ссылки
на старые панели. В фоне цикл обновления UI прекращается. Шейдеры создаются
при изменении размера, не на каждый draw. Приложение не резервирует память
пропорционально ОЗУ: даже профиль с 2 ТиБ получает те же фиксированные пределы.

Эти лимиты проверяются unit-тестами, но конкретный расход RAM на телефоне
не измерялся. Поддержку диапазона устройств от 2 ГБ нельзя подтвердить одной
сборкой: нужны замеры на реальных 32- и 64-битных устройствах.

## Сборка

Linux x86_64, JDK 17/21 с javac, Rust 1.90.0, SDK Platform 36,
Build Tools 36.0.0, NDK 27.2.12479018. Gradle Wrapper 8.13 проверяет SHA-256.

```sh
rustup target add armv7-linux-androideabi aarch64-linux-android i686-linux-android x86_64-linux-android
cargo test --workspace --locked
python3 -m unittest discover -s scripts -p 'test_*.py'
export ANDROID_HOME=/path/to/android-sdk
./scripts/build-android.sh
cd android
./gradlew testDebugUnitTest lintDebug
cd ..
python3 scripts/package-apks.py
```

Готовые именованные APK и SHA256SUMS.txt: `android/app/build/outputs/distribution/<версия>/`.
Не запускайте только Gradle после изменения Rust: сначала пересоберите JNI скриптом.
`CARGO_TARGET_DIR` поддерживается для повторного использования каталога сборки.

## GitHub Actions и тестовые выпуски

Push в main, pull request и ручной запуск проверяют Rust, Python-упаковку,
JVM-тесты очереди и профиля памяти, сборку всех ABI, Lint, подписи и 16-КБ упаковку.
Артефакты `luma-music-test-<номер>` хранятся 14 дней. Тег `v*` дополнительно создаёт
GitHub Pre-release после успешных проверок. Секреты Яндекс Музыки для CI не нужны.
Отладочные ключи разных CI-запусков могут отличаться: обновление через другую
подпись требует удаления старой установки, что удалит её локальные данные.

Автообновления: [план и требования к выпускному ключу](docs/UPDATES.md).
Не реализованы офлайн-загрузки каталога, редактирование плейлистов, эквалайзер,
тексты и публикация в магазине. Автотесты не подтверждают доступ к настоящему
каталогу, Bluetooth, звонки, OAuth-приложение или качество звука на устройстве.

Ориентир архитектуры: [PrivateMusicDesktop](https://github.com/decoder-dev/PrivateMusicDesktop).
Его исходники и ресурсы не копировались.
