# Luma Music icon

Новый оригинальный знак Luma для 1.3: мятная L и звуковая волна на графитовом фоне.
Исходное изображение создано для проекта; upstream YAYMA и знаки Яндекса не изменялись.

- luma-icon-source.png — исходное изображение.
- luma-icon.png — 512×512, палитра 96 цветов для небольшого размера.
- luma-icon.ico / .icns — контейнеры для desktop-пакетов.
- Android использует adaptive icon и отдельный векторный monochrome-вариант.

Файлы распространяются вместе с проектом по его лицензии GPL-3.0-only.
