# Luma Music 0.5.0

Первый стабильный канал текущей ветки. Android 11+ (min 30, target/compile 36),
четыре ABI и universal. Package `org.luma.music`, versionCode 18.

Release APK не debuggable, подписан прежним постоянным ключом: допускается
обновление поверх RC8 из Releases без удаления приложения. Android сам запрашивает
разрешение на установку; обхода этого диалога нет. При другой подписи обновление
поверх невозможно. Новые настройки OTA используют stable, сохранённый канал сохраняется.

Очередь запросов ограничена, устаревшие результаты не меняют новый экран.
Авторизованные HTTP-перенаправления ограничены исходным HTTPS-хостом.
В разделе информации показаны версия, тип выпуска, тема, язык и устройство;
диагностика без токенов дополнена качеством Wi-Fi/mobile и типом сети.

Проверки перед публикацией: Rust/JVM/Python, Android Lint, сборка четырёх JNI,
подпись и выравнивание 16 КБ. Отдельный workflow устанавливает RC8, обновляет его
release-сборкой без удаления данных и проверяет UI/JNI/MediaPlayer, тексты,
локали, RTL, фон и перезапуск на Android API 30 и 33, 2 ГБ RAM.
Результаты запуска записываются в GitHub Actions; это не замер расхода памяти.

Ограничения: 33 из 35 переводов частичные, с английским fallback. «Моя волна»,
авторизация и каталог зависят от неофициального API и подписки; автономные проверки
не заменяют проверку на настоящем аккаунте. Desktop остаётся отдельным интерфейсом
с ручным токеном в памяти, без полного паритета Android. Windows 7/8/8.1 —
экспериментальные portable-сборки, macOS без Developer ID/notarization.
