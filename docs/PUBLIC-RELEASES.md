# Публичные выпуски Luma Music

Репозиторий `Romeo13card-sys/Luma-Music` теперь публичный и используется как
единственный каталог готовых APK. Не нужно создавать второй репозиторий
или вводить пользовательский GitHub-токен в приложение.

## Что уже сделано

- GitHub-токен не нужен и не отправляется из приложения. Ранее сохранённый
  токен GitHub удаляется при обновлении; токен Яндекса не затрагивается.
- Проверка при запуске максимум раз в сутки, выключается в настройках.
- Скачивание, checksum, совпадение package/version/signature и системное подтверждение
  установки сохраняются. Автоматической установки без согласия пользователя нет.
- Локальный подписывающий скрипт хранит один ключ вне Git. Он не использует
  GitHub Secrets. Публикация выполняется отдельно от сборочного runner.

## Подпись в защищённой среде

В этой облачной среде каталог ключа: `/workspace/.luma-signing` (вне checkout).
Не удаляйте/не пересоздавайте его, не коммитьте и не выкладывайте на GitHub.
Ключ нужно отдельно резервировать в защищённое хранилище: существование
каталога здесь не гарантирует сохранность после удаления/пересоздания среды.
Не отправляйте ключ или пароль в чат.

Для другой доверенной машины используйте собственный путь вне checkout.
Первое создание:

```sh
python3 scripts/sign-local-apks.py --init-key \
  --key-dir /secure/path/luma-signing \
  --input android/app/build/outputs/distribution/0.5.0-rc.1 \
  --output android/app/build/outputs/family/0.5.0-rc.1
```

Для следующих версий та же команда без `--init-key` и с тем же key-dir.
Скрипт отказывается молча заменять отсутствующий/неполный ключ. Пароль
генерируется и хранится в закрытом файле, значения не выводятся в терминал.
В выходной папке только подписанные APK, SHA-256 и ПУБЛИЧНЫЙ fingerprint.

## Публикация

На машине с обычной авторизацией автора `gh auth login` (браузер, не секрет в CI):

```sh
scripts/publish-public-release.sh v0.5.0-rc.1 android/app/build/outputs/family/0.5.0-rc.1
```

Скрипт проверяет контрольные суммы, сертификаты и публичность целевого репозитория,
создаёт GitHub Pre-release. В этой среде вызов GitHub API пока заблокирован,
поэтому подписанные APK доступны локально, но публичная публикация не подтверждена.
Альтернатива — Releases → Draft a new release → загрузить подписанные файлы
из выходной папки, включая SHA256SUMS.txt.

Старые GitHub debug-APK имеют другой ключ. Новый постоянный семейный ключ не
обновит их поверх: для первоначального перехода потребуется отдельное решение
владельца. Не удаляйте старую установку без учёта потери её локальных данных.
После установки первого семейного APK все следующие семейные выпуски должны
использовать тот же ключ, applicationId org.luma.music и больший versionCode.

Родственникам нужны только публичный APK и подтверждение установки Android.
Сервис подписи не работает круглосуточно сам по себе: новый выпуск надо собрать,
подписать и опубликовать. OAuth-настройка входа Яндекса остаётся отдельным вопросом.
