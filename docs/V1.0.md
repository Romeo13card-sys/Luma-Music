# Luma Music 1.0

База сравнения — опубликованная 0.5.0. Работа ведётся в main.

## Критерии готовности

1. Material Design 3 на нативных Views: навигация, кнопки, темы, экраны без постоянных эффектов.
2. Доступные MP3 Яндекс Музыки сохраняются в приватное хранилище, воспроизводятся без сети;
   неполный файл не показывается готовым. Есть лимит места, удаление и только Wi-Fi.
3. Аккаунты Яндекса и Spotify хранятся раздельно. Spotify OAuth использует PKCE,
   одноразовый state и проверку callback. Ограничения воспроизведения показаны в интерфейсе.
4. CHANGELOG.md и экран «Что нового» содержат фактические изменения.
5. Проверки и сборки запускаются из main. Сохраняются org.luma.music, семейный сертификат,
   Android 11+, SDK 36 и четыре ABI. Статус стабильной версии выдаётся после проверок.

## Проверка

Rust-тесты загрузок/файлов/лимитов и OAuth, JVM-проверки, Lint, сборка четырёх JNI.
Android-интеграция на 2 ГБ: запуск, обновление с 0.5.0, офлайн-воспроизведение,
тексты, состояние загрузок, навигация и перезапуск. Действительный аккаунт и Client ID
нужны для проверки внешних музыкальных сервисов; заглушка не заменяет такой тест.


## Реализовано в dev.1

MDC 1.13 / Material 3, нативная навигация и кнопки, динамический акцент Android 12+.
Офлайн-ядро Rust и Android foreground service, один трек за раз с отменой,
проверкой целостности, выбором качества, лимитом места и разделением по аккаунтам.
Spotify OAuth PKCE, отдельное хранилище токенов, обновление сессии, страницы
плейлистов/избранного и передача воспроизведения Spotify. CHANGELOG.md встроен
в экран «Что нового». Известные ограничения перечислены в истории изменений.

Проверки и публикация идут из main. Для локально подписанных APK используется
временный каталог .release-input в main; CI проверяет сертификат и исходники.
Для Android-интеграции используется .smoke-input в main. После обработки файлы
удаляются следующим коммитом main, а подписанные APK остаются в Releases.
Desktop запускается workflow_dispatch с tag или файлом .github/release-request.json
с полем tag. Закрытый ключ остаётся вне репозитория.
