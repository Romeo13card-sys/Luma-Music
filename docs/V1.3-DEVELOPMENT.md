Сохраняются main-only, org.luma.music, постоянная подпись, API30–36,
нативный Kotlin UI и бизнес-логика Rust. AGENTS.md не создавать.
Первый сетевой запуск зависит от сервера/соединения; мгновенный старт возможен
для уже подготовленного трека. Сетевые API проверять отдельно от fixture-тестов.
