# OTA GitHub в 0.4.0

Настройки → Обновления: stable/test, проверка выпуска, описание, скачивание
под ABI устройства, SHA-256, проверка packageName, versionCode, minSdk и
совпадения сертификата с установленным приложением. APK читается и записывается
потоком по 32 КБ, максимум 100 МиБ. Проверяются размер, свободное место и
контрольная сумма из SHA256SUMS.txt. Редиректы только на разрешённые HTTPS-хосты
GitHub; личный токен отправляется только api.github.com.

Установка через системный установщик с подтверждением пользователя и явным
разрешением на установку из Luma Music. ContentProvider даёт чтение только одного
файла update.apk в закрытом каталоге кэша, без доступа к токенам или прочим файлам.
Есть установка заранее скачанного APK с теми же проверками сертификата и версии.

Источник обновлений — отдельный публичный каталог Luma-Music-Releases.
Пользовательский GitHub-токен не нужен, отправка Authorization удалена.
Проверка при запуске ограничена одним разом в сутки.
[Основной семейный маршрут](PUBLIC-RELEASES.md).

Обязательная настройка подписи: [SIGNING.md](SIGNING.md). Обновление поверх старой
GitHub debug-сборки не гарантируется и без исходного закрытого ключа невозможно.
Наличие кода OTA не подтверждает скачивание/установку на настоящем устройстве.
Ротация ключей и восстановление закрытого ключа не реализованы.
