# План обновлений с GitHub

Автообновление не включено в 0.3.0. До его включения нужны:

1. Постоянный выпускной ключ вне Git и защищённые GitHub Actions Secrets.
   Отладочные ключи разных CI-запусков не подходят для цепочки обновлений.
2. Каналы stable/test, ручная проверка обновлений, показ версии и изменений.
3. HTTPS-загрузка в файл, без хранения APK целиком в RAM; ограничение размера,
   SHA-256, совпадение packageName org.luma.music и сертификата установленного APK,
   проверка versionCode. При любой ошибке установка запрещается.
4. Установка через системный установщик с подтверждением пользователя.
5. Для приватного репозитория нужен отдельный способ доступа к выпускам.
   GitHub PAT автора нельзя встраивать в приложение. Альтернатива — публичный
   репозиторий только для подписанных выпусков.

Выпускной ключ нельзя отправлять в чат или коммитить в исходники.
