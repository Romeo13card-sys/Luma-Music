# Правила работы с репозиторием

- Все изменения, коммиты и отправку кода выполнять только в `main`.
- Не создавать и не использовать дополнительные рабочие, release-, проверочные
  или транспортные ветки, включая временные ветки для APK и desktop-сборок.
- Проверки и публикацию организовывать из `main` через GitHub Actions;
  если существующий workflow требует отдельной ветки, адаптировать его для
  `main` или `workflow_dispatch`, не создавая служебную ветку.
- Для каждой версии вести понятный `CHANGELOG.md` и заметки GitHub Releases:
  добавленное, изменения, исправления, известные ограничения и совместимость
  обновления относительно предыдущего выпуска. Планы отделять от готовых функций.
