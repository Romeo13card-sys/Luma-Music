# История изменений Luma Music

## 2.1.0 — стабильный выпуск

- Ускорена подготовка аудиопотока на Android: предварительное разрешение адресов выполняется в фоне, обычное воспроизведение больше не ждёт предварительный запрос и сразу присоединяется к общему запросу ядра, если он уже выполняется.
- Rust-ядро объединяет одновременные запросы одного трека и качества, хранит до восьми краткоживущих адресов в памяти и разделяет кэш по аккаунту.
- Desktop использует общий кэш потоков и заранее прогревает адрес следующего доступного трека.
- Desktop получил проверку стабильного GitHub-релиза и загрузку подходящего ZIP-архива для текущей ОС/архитектуры с обязательной проверкой опубликованного SHA-256; добавлена установка проверенного архива с перезапуском Desktop на Windows, Linux и macOS; реальная проверка установщика на каждой ОС ещё требуется.
- Версия Desktop синхронизирована с базовой стабильной версией 2.0.0; сравнение обновлений поддерживает отображаемую форму `2.0`.
- Добавлены регрессионные тесты для ASCII ID треков, конкурентного разрешения потока и выбора следующего трека для предварительной загрузки.

В Android убраны текстовые сообщения о штатной загрузке: ошибки по-прежнему отображаются, а подготовка трека не засоряет экран статусами. Подправлены отступы и размеры мини-плеера. Стабильный Android APK использует versionCode 28 и versionName 2.1.0; Desktop синхронизирован с 2.1.0.


## 2.0.0 — подготовка стабильного выпуска

- Стабильная версия приложения: versionCode 26, versionName 2.0.0.
- Обновлённый Android-интерфейс и оболочка, новый Desktop layout.
- OTA-загрузки в постоянное хранилище с продолжением прерванной загрузки GitHub,
  проверкой SHA-256, версии, package ID и сертификата перед установкой.
- Повторная проверка сохранённого APK перед установкой после перезапуска.
- Исправлено восстановление частично загруженного APK после ошибок чтения/записи.
- Добавлена регрессия выбора стабильного обновления с 1.3 до 2.0 и исключения RC
  из стабильного канала.

**Важно об установке:** для 2.0 создаётся новый постоянный ключ подписи. Если
установлена версия 1.3, подписанная прежним ключом, Android потребует удалить её
перед первой установкой 2.0. После перехода все последующие обновления 2.x будут
устанавливаться поверх с сохранением данных при сохранении нового ключа.

Релиз будет опубликован после создания и резервного копирования ключа подписи,
сборки пяти APK, проверки подписей и публикации GitHub Release.

## 2.0.0-rc.1 — кандидат на выпуск

Первый release-candidate APK собран с versionCode 25. CI run `44929979527` на
commit `ec8a5002fe8600c8b7db81923d37c7cb1d4c1217` завершился успешно: Rust fmt и
tests, APK packaging tests, оптимизированные native libraries, Android unit
tests, Lint, пять ABI-вариантов APK, подписи installable Debug APK и 16-КБ
выравнивание прошли. Артефакт `luma-music-installable-debug-apks-272` содержит
ARM64, ARMv7, universal, x86 и x86_64; контрольные суммы всех пяти APK после
скачивания артефакта совпали с `SHA256SUMS.txt`.

Debug APK подписаны временным ключом GitHub runner и предназначены только для
тестирования. Они не являются стабильным выпуском.

Продолжается расширенный план: [V1.3-DEVELOPMENT.md](docs/V1.3-DEVELOPMENT.md).
После просьбы пользователя выдать APK быстрее, проверенные плеер, настройки

## 1.3 — относительно 1.2

### Добавлено

- Подготовка одного следующего трека заранее и короткий кэш четырёх адресов потоков в памяти (45 секунд, отдельно по аккаунту и качеству).
- При выборе неподготовленного трека текущий звук сохраняется до готовности нового. Первый сетевой запуск зависит от ответа сервера и соединения.
- Возобновление после временной потери аудиофокуса и ожидание занятого аудиовывода.
- Обновлённые настройки: 12 разделов с группами и подпунктами. Отдельно качество музыки, звук, сеть/предзагрузка, офлайн-загрузки, Моя волна и тексты.
- Баланс каналов, открытие системного эквалайзера, одноразовый таймер до конца трека, отдельный размер текста песни и переключатель подсветки слов.
- Новая иконка Luma: adaptive icon, monochrome для Android 13+ и отдельный белый знак уведомления.

### Установка и проверки

- APK устанавливается поверх 1.2: прежние org.luma.music и постоянный сертификат, versionCode 23. Удалять приложение не нужно.
- Android 11+, SDK 36, ARMv7/ARM64/x86/x86_64 и universal. Для большинства телефонов выбирайте arm64-v8a, universal включает все архитектуры.
- Проверено обновление 1.2 → 1.3, запуск и повторный запуск на Android API30/33 с 2ГБ ОЗУ.
- Проверены подготовленный MediaPlayer, переключение без повторной подготовки, возврат аудиофокуса, очередь, новые разделы настроек, тексты и локали.
- 74 теста Rust-ядра, JVM/Lint и упаковка прошли. Это не подтверждение сетевых сценариев на настоящем аккаунте.

### Что ещё в работе

- Расширенный каталог альбомов/исполнителей, редактор плейлистов, очередь скачивания и остальные пункты большого плана.
- Интерфейс истории/закладок/резервных копий пока не включён в этот APK; в источнике подготовлен Rust-модуль.
- Нового интерфейса desktop в этом выпуске нет. Desktop-ресурсы иконки подготовлены в исходниках.
